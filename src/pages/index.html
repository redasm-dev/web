Plugin architecture

REDasm provides a C API, carefully designed to be simple and intuitive to use.
The C API makes it easy to integrate other programming languages and the core library is designed to be used headless for automated analysis.

Nightly Builds

Nightly builds are automatically generated from the latest commits, giving you access to the newest features and fixes.

Signature Verification

Builds are signed.
Each release ships a .sha256 and a matching .sha256.asc signature, both available on the GitHub release page. 

# import public keys
gpg --keyserver keys.openpgp.org --recv-keys B0C728D7021EEEE9D9B859043AF46EB2201FFB56 # releases
gpg --keyserver keys.openpgp.org --recv-keys A2391AFACAE2EE52B35541DD65F948A2F6BB294A # nightly

# verify linux
gpg --verify REDasm-VERSION-x86_64.AppImage.sha256.asc REDasm-VERSION-x86_64.AppImage.sha256
sha256sum -c REDasm-VERSION-x86_64.AppImage.sha256

# verify windows
gpg --verify REDasm-VERSION-windows-x86_64.zip.sha256.asc REDasm-VERSION-windows-x86_64.zip.sha256
sha256sum -c REDasm-VERSION-windows-x86_64.zip.sha256

# for nightly builds (replace VERSION with "nightly")
gpg --verify REDasm-nightly-x86_64.AppImage.sha256.asc REDasm-linux-x86_64.AppImage.sha256
sha256sum -c REDasm-nightly-x86_64.AppImage.sha256

Packages

REDasm is also available in various package managers, which provide a more integrated installation & update experience.

Scoop
Official 

scoop install git
scoop bucket add redasm https://github.com/redasm-dev/scoop-redasm
scoop install redasm

Arch Linux (AUR)
Official 

Replace `yay` with your AUR helper.
# beta
yay -S redasm-beta
# nightly
yay -S redasm-git

Pentoo

Split in various packages:
- libredasm
- redasm-gui
- redasm-loaders
- redasm-processors
- redasm-analyzers
